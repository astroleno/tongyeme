# tongyeme

Static site for 同野观幂, synced from the latest TongyeGuanmi website worktree.

## Commands

- `npm run build:page` rebuilds `index.html` from `src/index.template.html`.
- `npm run dev` serves the static site locally.
- `npm run verify:homepage-transitions` checks the homepage transition integration.

## Archive

- `/archive/previous` serves the previous synced site snapshot.
